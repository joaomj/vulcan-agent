Vulcan Agent — System Architecture

Local-first Rust coding agent: web UI (PWA), worktree isolation, MCP extensibility

Core Priorities

  • • Performance: native Rust binary, startup < 1 s, idle < 128 MB
  • • Stability: event sourcing, idempotent tools, full worktree reset
  • • Portability: browser (PWA), single binary, only needs git
  • • Extensibility: MCP servers, on-demand skills, provider abstraction

Key Design Choices

  • • WebSocket-only client transport (no SSE hybrid)
  • • One git worktree per session, nested for subagents
  • • Shell git via tokio::process::Command for reliability
  • • SQLite append-only event store and audit log

Extension Points

  • • MCP: stdio/SSE servers merged into tool registry
  • • Skills: SKILL.md loaded on demand via tool call
  • • Providers: generic OpenAI-compatible first; Anthropic later
  • • Future loops: session model leaves room for /goal, evaluators
